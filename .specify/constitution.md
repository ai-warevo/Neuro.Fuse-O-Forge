# Neuro.Fuse-O-Forge Constitution

## Project Name
Neuro.Fuse-O-Forge

## Participants
1. Spec-Engineer (You)
2. AI (The only code executor)

## Objectives and Tasks
1. Development of a modular platform for generating and merging neural network data, starting with AudioGen.
2. Fully automated development cycle.

## Project Structure
```
/backend/{api, worker} (FastAPI + Workers)
/frontend (Next.js)
/volumes (data and model weights)
/docker-compose.yml
/.specify (project memory)
```

## Technologies
- **Backend:**
  - Python 3.10+
  - FastAPI
  - SQLAlchemy (Async)
  - Redis (Streams for tasks, Pub/Sub for logs)

- **ML:**
  - PyTorch
  - Transformers
  - Audiocraft

- **Frontend:**
  - Next.js (App Router)
  - Zustand
  - Tailwind CSS
  - Bun runtime

- **Infrastructure:**
  - Docker Compose
  - Multi-stage Dockerfiles

## Specific Requirements
1. **No Human Code:** 100% code generation by AI. Any modifications must be through specification clarifications.
2. **Hardware Optimization:** Optimized for RTX 4080 (16GB VRAM) and Ryzen 9800X3D.
3. **Workflow:**
   - Spec -> Clarify -> Plan -> Tasks -> Implement

## Workflow Guidelines
1. **Spec (Specification):** Define the requirements and scope of work.
2. **Clarify:** Provide detailed clarifications on any ambiguous points from the specification.
3. **Plan:** Develop a detailed plan for implementation, including tasks and timelines.
4. **Tasks:** Execute individual tasks as outlined in the plan.
5. **Implement:** Deploy and integrate all completed tasks to ensure they meet the specified objectives.

## Code Generation Guidelines
1. **AI Code Generation:** All code must be generated by AI following the provided specifications.
2. **Specification Clarifications:** Any changes or updates to the specification must be done through clarification requests.

## Hardware Optimization Guidelines
1. **RTX 4080 (16GB VRAM):** Ensure all models and computations are optimized for this GPU.
2. **Ryzen 9800X3D:** Optimize CPU-intensive tasks for optimal performance on this processor.

## Compliance and Maintenance
1. **Compliance Checks:** Regularly review the code and implementation to ensure compliance with specifications and requirements.
2. **Maintenance:** Continuously update and maintain the system to adapt to new technologies and optimize performance.

**Note:** This constitution is a living document and may be updated as the project evolves. All changes must follow the same workflow guidelines.
